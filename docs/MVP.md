# MVP - Language Reading App

## 1. Overview

A web application that helps users learn a new language through reading AI-generated books at an appropriate difficulty level.

Books are generated by an LLM before being made available to users.

The applications utilises both progressive reading difficulty alongside context-aware translation to help users understand unfamiliar words and phrases without leaving the reading experience.

---

## 2. Core User Journey

1. User creates an account.
2. User selects a language they want to learn.
3. User selects their reading level.
4. User browses available books.
5. User opens a book and begins reading.
6. User selects an unfamiliar word or phrase.
7. The application provides a contextual translation.
8. User continues reading.
9. The application saves their reading progress.
10. User can return later on and continue from where they stopped.

## 3. MVP Features

### Authentication

- User registration
- User login 
- User logout 

### Language & difficulty

- Select a language to learn
- Select a reading level
- Books have difficulty levels

### Books & Reading

- Browse available books
- View book information
- Open and read a book
- Navigate through chapters/pages

### Translation 

- Selects an unfamiliar word
- Display its translation
- Select multiple consecutive words 
- Translate the selected phrase using its surrounding context 

### Progress 

- Save the user's reading position
- Resume a book from their previous position 
- Display basic reading progress 

### 4. Out of Scope

The following features are not included within the initial MVP:

- Flashcards
- Spaced repetition
- Gamification
- Leaderboards
- Advanced recommendations

--- 

## 5. Success Criteria

The MVP is complete when a user can:

1. Create an account.
2. Select a language and reading level.
3. Find an appropriate book. 
4. Read the book within the application. 
5. Translate unfamiliar words or phrases contextually.
6. Leave the application.
7. Return later and resume reading from their previous position
