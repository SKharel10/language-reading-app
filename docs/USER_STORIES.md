# MVP User Stories — Language Reading App

## Authentication

- **US-01:** As a learner, I want to create an account so that my progress can be saved.
- **US-02:** As a learner, I want to log in so that I can access my account.

## Language & Difficulty

- **US-03:** As a learner, I want to select a language so that I can access relevant books.
- **US-04:** As a learner, I want to select my reading level so that I can find appropriate books.

## Reading

- **US-05:** As a learner, I want to browse available books so that I can choose something to read.
- **US-06:** As a learner, I want to read a book within the application so that I can practise my target language.

## Translation

- **US-07:** As a learner, I want to select an unfamiliar word and see its translation so that I can understand it.
- **US-08:** As a learner, I want to select a phrase and receive a context-aware translation so that its meaning is preserved.

## Progress

- **US-09:** As a learner, I want my reading position to be saved so that I can continue reading later.
- **US-10:** As a learner, I want to resume a book from where I stopped so that I can continue reading.

## AI-Generated Content

- **US-11:** As a learner, I want access to a library of pre-generated books appropriate to my language and reading level.

> User-generated/on-demand book generation is outside the MVP.
